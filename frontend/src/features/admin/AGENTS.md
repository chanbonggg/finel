# Admin Feature 작업 가이드

## 책임

`features/admin`은 관리자 제품·카테고리·문의 UI와 해당 client hook을 소유한다. route는 `app/chanyoung`, HTTP 계약은 `lib/api`가 소유한다.

## 규칙

- 목록은 관리자 전용 API를 사용한다. 숨김 제품 수정은 공개 상세를 다시 조회하지 말고 관리자 목록 상태를 기준으로 한다.
- 제품/카테고리/inquiry mutation 뒤 로컬 상태를 정확히 갱신하고, 업로드·저장 중 중복 클릭을 막는다.
- 401은 로그인으로 이동한다. 403 CSRF, 404 stale data, 409 중복/사용 중, 429 제한을 구분해 안내한다.
- 삭제는 명시적 확인 후 수행하며 성공한 항목만 목록에서 제거한다.

## 검증

관리자 로그인 후 제품 CRUD(숨김 포함), 카테고리 생성/삭제 거부, 문의 삭제, 이미지 업로드 오류를 확인한다.
